# Tugas Proyek - Katalog Usaha UMKM Mandiri

Website profil dan katalog produk interaktif untuk usaha mikro (UMKM) yang dilengkapi fitur keranjang belanja dinamis.

## Struktur File
- `index.html`: Kerangka semantik HTML5 (header, nav, main, section, article, aside, footer).
- `style.css`: Tata letak responsif menggunakan CSS Grid dan Flexbox.
- `script.js`: Logika keranjang belanja dinamis dan perhitungan total pembayaran.

## Catatan Pemakaian AI (AI Disclosure Log)
Sesuai kebijakan mata kuliah, berikut adalah rincian bagian yang dibantu oleh AI dalam proyek ini:
- **Struktur Kode & Styling:** Pembuatan kerangka dasar HTML5 semantik (`index.html`) dan pengaturan tata letak responsif (`style.css`).
- **Logika JavaScript:** Pembuatan fungsi interaktif tambah/hapus keranjang belanja (`addToCart`, `removeFromCart`, `updateCartUI`) pada `script.js`.
- **Manajemen Git:** Panduan pembuatan file dan unggah repositori ke GitHub.
